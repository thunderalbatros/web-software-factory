## 3. Core Astro 5 Primitives for Factory Agents

### 3.1 Partial Hydration (Client Islands)
By default, an `.astro` component compiles to **100% static HTML and CSS with 0 bytes of client-side JavaScript**. Interactive components only hydrate when explicitly annotated with a client directive:
- `client:load` — Hydrates immediately on page load (use ONLY for above-the-fold interactive heroes or navigation).
- `client:idle` — Hydrates via `requestIdleCallback` after the main thread is free.
- `client:visible` — Hydrates via `IntersectionObserver` only when the user scrolls near the component (mandatory for below-the-fold pricing calculators, carousels, or contact forms).

### 3.2 Server Islands (`server:defer`)
Allows caching the entire page shell at the CDN edge while deferring personalized or dynamic sub-components (e.g., user avatar, live stock/availability badge, regional pricing):
```astro
---
import UserBadge from '../components/UserBadge.astro';
---
<UserBadge server:defer>
  <div slot="fallback" class="skeleton-pill" aria-hidden="true">Cargando...</div>
</UserBadge>
```

### 3.3 Content Layer API (`src/content.config.ts`)
Astro 5 replaces legacy content folders with the unified **Content Layer API**, capable of loading Markdown, JSON, YAML, or remote APIs at build time with strict Zod validation:
```typescript
import { defineCollection, z } from 'astro:content';
import { glob } from 'astro/loaders';

const services = defineCollection({
  loader: glob({ pattern: '**/*.md', base: './src/data/services' }),
  schema: z.object({
    title: z.string(),
    summary: z.string().max(160),
    priceLabel: z.string().optional(),
    featured: z.boolean().default(false)
  })
});

export const collections = { services };
```

## 4. Cloudflare Workers Static Assets Configuration (`wrangler.toml`)

Every project generated by the Software Factory deploys to **Cloudflare Workers Static Assets** (which supersedes legacy Cloudflare Pages):

```toml
name = "client-project-id"
compatibility_date = "2025-02-01"

[placement]
mode = "smart"

[assets]
directory = "./dist"
binding = "ASSETS"
```

And every build (`node tools/factory.mjs build --project <id>`) automatically generates `dist/_headers` with:
- `Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`
- Strict `Content-Security-Policy` (blocking inline XSS scripts while permitting `application/ld+json` and `inline-speculation-rules`)
- `Cache-Control: public, max-age=31536000, immutable` on `/_astro/*`, `/assets/*`, and `/site/images/*`.
