# Buzón de Cursos en Video, Conferencias y Papers (`knowledge/_inbox_courses/`)

Arrastrá aquí transcripciones de cursos (`.srt`, `.vtt`, `.txt`, `.md`), charlas técnicas o papers y ejecutá:

```powershell
npm run cto:destilar-curso
```

El destilador elimina el 80%+ del relleno conversacional y genera una salida dual en `knowledge/` (`TIER_1_SOTA_2026`) y `.agents/skills/`.
