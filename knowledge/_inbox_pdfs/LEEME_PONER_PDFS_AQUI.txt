   BUZON PRIVADO DE LIBROS Y TRATADOS PDF / EPUB — WEB SOFTWARE FACTORY
================================================================================

¿COMO FUNCIONA ESTE BUZON?

1. Arrastra o copia dentro de esta carpeta (`knowledge/_inbox_pdfs/`) cualquier
   libro tecnico, manual o tratado en formato `.pdf`, `.epub` o `.md` que hayas
   descargado en tu computadora:
   - Refactoring UI (Wathan & Schoger)
   - Practical UI (Adham Dannaway)
   - $100M Offers / $100M Leads (Alex Hormozi)
   - Breakthrough Advertising (Eugene Schwartz)
   - Making Websites Win (Karl Blanks & Ben Jesson)
   - Thinking, Fast and Slow (Daniel Kahneman)
   - Cualquier otro libro de UI/UX, Copywriting, SEO, Arquitectura o Seguridad.

2. Ejecuta en la terminal el comando simple:

   npm run cto:ingerir-libros

3. El motor `tools/intelligence/book_pdf_ingester.mjs` hara automaticamente
   todo el trabajo por vos:
   - Extraera el 100% del texto, tablas, formulas y bloques de codigo (Docling /
     RAG-Anything 4-Track Parser).
   - Limpiara encabezados rotos, numeros de pagina y artefactos de escaneo con
     `rag_library_sanitizer.mjs`.
   - Clasificara el libro en la subcarpeta correspondiente de `knowledge/`
     (`ui_ux_design`, `software_factory`, `architecture_and_books`,
     `cybersecurity`, o `motion_and_animation`).
   - Movera el archivo PDF/EPUB original a `knowledge/_inbox_pdfs/procesados/`
     para no procesarlo dos veces.
   - Reconstruira el indice neuronal `Omni-RAG v5` automaticamente.
