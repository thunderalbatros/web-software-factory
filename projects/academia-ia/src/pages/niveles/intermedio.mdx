# Búsqueda aumentada local (RAG) con SQLite y vectores abiertos

Cuando conectas un modelo abierto a tus propios manuales, evitas que responda de memoria. Primero recuperas los pasajes pertinentes de tu base local y luego pides una síntesis sujeta a esas citas.

Este patrón funciona en una computadora estándar sin pagar servidores externos. Solo necesitas dividir tus documentos en bloques breves y guardarlos en un archivo `SQLite` bajo tu control.

## Cómo mide cercanía un índice híbrido

Los *embeddings* convierten cada párrafo en una lista de números reales. Para estimar qué pasaje se parece más a tu pregunta, medimos el ángulo entre ambos vectores con la similitud coseno:

### Por qué unir texto exacto y vectores

Los vectores capturan ideas parecidas aunque cambien las palabras, pero a veces fallan con códigos de pieza o artículos de ley exactos. Al unir `FTS5` con vectores obtienes precisión léxica y contexto semántico a la vez.

```js
// Consulta local en Node.js v24 con SQLite nativo (costo de servidor $0.00 USD)
import { DatabaseSync } from 'node:sqlite';

const db = new DatabaseSync(':memory:');
db.exec('CREATE VIRTUAL TABLE docs USING fts5(slug, body);');
db.prepare('INSERT INTO docs (slug, body) VALUES (?, ?)').run(
  'guia-rag',
  'Verifica cada respuesta exigiendo el identificador exacto del pasaje fuente.'
);

const hits = db.prepare('SELECT slug, body FROM docs WHERE docs MATCH ? LIMIT 3').all('pasaje');
```

### Regla de oro antes de mostrar la salida

Exige que el programa devuelva siempre la cita literal junto al texto generado. Si ningún fragmento supera el umbral mínimo, el asistente debe responder con honestidad que no consta en tus documentos.
