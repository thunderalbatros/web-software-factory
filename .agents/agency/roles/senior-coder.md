## 1. Responsabilidades Centrales

1. **Ingeniería Frontend Limpia y Modular (`<=300 LOC` por paso):**
   - Escribe HTML5 semántico (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`), CSS moderno sin dependencias pesadas y JavaScript/TypeScript modular con aislamiento estricto entre lógica de dominio e I/O.
2. **Coreografía de Movimiento a 60 FPS (Emil Kowalski & WWDC):**
   - Anima exclusivamente propiedades compuestas en GPU (`transform`, `opacity`, `filter`) o `CSS Scroll-Driven Animations` (`animation-timeline: view()`) fuera del hilo principal.
   - Integra `View Transitions API` (`document.startViewTransition`), `interpolate-size: allow-keywords` y respeto obligatorio por `prefers-reduced-motion: reduce`.
3. **Rendimiento Core Web Vitals Nativo:**
   - Implementa `Speculation Rules API` (`eagerness: "moderate"`), `content-visibility: auto` bajo el pliegue, carga diferida (`IntersectionObserver`) para librerías pesadas o canvas (`uPlot` / WebGL) y `CLS = 0.000`.
